# 片名卡与封面设计

片名卡不是"打一行字"。`filmbench/title` 把它拆成四层，任何一层没想清楚都会显得廉价。

## 四层结构

| 层 | 作用 | 排版 | 例子 |
| --- | --- | --- | --- |
| **kicker** | 系列/期号，建立出处 | 等宽小字，字距 0.4em，透明度 ~0.6 | `FILMBENCH 短片 01` |
| **title** | 片名，唯一的视觉重心 | 宋体，字号 ≈ 画宽/9，字距 0.1em | `最 后 一 单` |
| **rule** | 分隔，也是唯一的彩色元素 | 2px 细线，宽度 ≈ 3.2 个标题字，accent 色 | 暗红 `#ad3a20` |
| **subtitle** | 一句剧情钩子，不是重复片名 | 无衬线，字号 ≈ 标题 0.2，字距 0.22em，透明度 0.74 | `雨夜 · 一栋待拆的楼 · 最后一单包裹` |
| **credits** | 年份/时长/规格，压在左下角 | 等宽，透明度 0.45 | `2026 · 20s · 1344×768` |

背景三选一：
- **剧照 + 压暗**（`references` 给一张，`scrim` 控制压到多黑）：最能建立"这支片子的世界"，但要压到 0.66–0.75，否则字浮在图上看不清；
- **纯色**（`bg`）：适合极简或系列片头；
- **纸面**（`preset: paper`）：浅色底、深色字，适合作者向/纪录。

再叠**暗角**（radial）与**确定性颗粒**（900 个固定伪随机点，不依赖 `feTurbulence`），画面才不像 PPT。

## 三个预设

| preset | 用途 | 视觉 |
| --- | --- | --- |
| `noir`（默认） | 夜戏、悬疑、都市 | 深色、剧照压暗、居中大字、红色细线 |
| `paper` | 作者向、纪录、文学改编 | 纸色底、墨色字、左侧对齐 |
| `minimal` | 系列片头、实验 | 纯色底、居中、几乎无装饰 |

## 怎么"根据剧情"写

- **title**：短、有动作或物件。`最后一单` 比 `雨夜的故事` 好——前者已经含了叙事。
- **subtitle**：给"这一支片子独有的三个名词"，不写情绪形容词。
  - 好：`雨夜 · 一栋待拆的楼 · 最后一单包裹`
  - 差：`一个关于孤独与救赎的温暖故事`
- **kicker**：只写系列与期号，不要写导演阐述。
- **credits**：机器能读的事实（年份/时长/规格/版本），别写"用心之作"。

## 封面

封面直接复用一次标题卡：把 `references` 指向最能代表片子的那一镜（这里是门厅），
`scrim` 压低、标题压上去，`filmbench cover --shot title` 把它设为封面。
这样封面和片头是同一套设计语言，不会两张皮。

## 参数

```yaml
impl: { profile: filmbench/title, task: title, params: {
  preset: noir,
  text: 最后一单,
  kicker: "FILMBENCH 短片 01",
  subtitle: "雨夜 · 一栋待拆的楼 · 最后一单包裹",
  credits: "2026 · 20s · 1344×768",
  size: 168, scrim: 0.7, accent: ad3a20, grain: true
} }
```
